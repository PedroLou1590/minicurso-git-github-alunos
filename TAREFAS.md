# Tarefas de correção

**Escolha somente o módulo indicado pelo instrutor.** Os comportamentos esperados são documentados nos próprios arquivos Python. Não há necessidade de instalar bibliotecas.

| Tarefa | Arquivo | O programa deveria... |
|---|---|---|
| A | `soma.py` | devolver a soma de dois valores, inclusive negativos. |
| B | `concatenacao.py` | manter a ordem dos textos concatenados. |
| C | `paridade.py` | identificar corretamente inteiros pares, inclusive zero. |
| D | `media.py` | calcular a média real de uma lista não vazia. |
| E | `vogais.py` | contar vogais sem diferenciar maiúsculas de minúsculas. |
| F | `maior.py` | encontrar o maior dos três argumentos. |

## Critérios de conclusão

- [ ] Executei o doctest antes da correção e observei os resultados.
- [ ] Encontrei o erro e fiz uma correção pequena e legível.
- [ ] Mantive os nomes das funções e os exemplos da docstring.
- [ ] Acrescentei **um novo exemplo doctest relevante**, correto e que passa.
- [ ] Executei o teste do meu módulo e obtive **0 falhas**.
- [ ] Revisei meu `git diff` para garantir que só alterei o arquivo da tarefa.
- [ ] Criei a branch, o commit e a Pull Request nos padrões exigidos.
- [ ] Expliquei na PR o problema, a solução e os testes executados.

## Extra opcional

Acrescente um caso de borda ao doctest (zero, vazio, repetição ou valores negativos, conforme a função). Evite alterar contratos ou introduzir dependências externas sem combinar com os instrutores.
